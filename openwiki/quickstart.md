# HA-SNMP quickstart

Home Assistant add-on: SNMP v2c agent exposing selected HA entities (and host info) to LibreNMS / Nagios-style monitors.

## Stack

- Home Assistant add-on (`config.json`, `Dockerfile`, `data/`)
- Python helpers under `data/`
- Validate: `scripts/validate`
